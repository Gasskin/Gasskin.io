# 万象棋对局统计

## 更新数据

1. 将所有对局整理到本目录的 `data.xlsx`，每个 Sheet 对应一项赛事，Sheet 名即赛事名（例如“风云杯”“新人杯”），保存 Excel。
2. 双击 `生成数据.bat`。需要 Python 3；首次运行若缺少 openpyxl，会通过 pip 安装本目录 requirements.txt 中的依赖。
3. 生成成功后会自动运行项目 `build.py`，将页面和 JSON 同步到 `docs/`。刷新网站中的“万象棋”分页。

玩家列表上方可勾选一个或多个赛事，“所有赛事”用于全选或取消全选。排名、参赛场数、玩家均值和全体均值随筛选更新；切换时保留参赛的当前玩家，否则选中榜首，并清空玩家搜索。未勾选任何赛事时清空展示并提示选择；空白 Sheet 不出现在赛事列表中。

“当前玩家”旁的“对比目标”默认选择“平均值”（所选赛事内所有玩家均值），也可选择当前赛事范围内的其他玩家。雷达图、图例和平均数据表同步更新。切换玩家或赛事时保留有效的对比目标；目标与当前玩家相同或不在所选赛事中时恢复为平均值。

本地浏览使用项目根目录的 `python dev_server.py`，打开 `http://127.0.0.1:8765/#wxq`。请通过 HTTP 访问，直接双击 HTML 无法读取 JSON。更新线上网站仍需按项目现有 GitHub Pages 流程发布。

## Excel 格式

读取所有工作表，包括隐藏工作表；名称以 `##` 开头的工作表（例如 `##散排`、`##备注`）整张跳过，不校验内容，也不计入统计或赛事筛选。名称中间包含 `##` 的工作表仍正常处理。其余每张表按前七列解析，依次为：

`ID | 排名 | 获得能量/经济 | 对棋手伤害/攻击 | 总回合数/生存 | 单回合最多升级/成长 | 单回合最多出牌/操作`

首列为 `ID` 的行开始新对局，直到下一个表头或当前工作表结束。空行跳过，不切分对局；空白工作表跳过。维度按 `/` 后面的名称识别，顺序保持一致。不带前缀的“经济”等表头也支持。

- 玩家 ID 去除前后空格后精确匹配，不同 Sheet 中相同 ID 合并。
- 同一场不允许重复 ID；错误提示包含 Sheet、行号和 ID。
- 排名必须为正整数；其余指标必须为非负有限数值。零为有效数据，空值和错误值不能充当零。
- 如果使用 Excel 公式，需要先在 Excel 中计算并保存；脚本读取已保存的计算结果。
- 所有数据校验通过才写入 JSON；校验失败保留上次 JSON，不修改源 Excel。

## 统计和文件

- 单玩家均值只计算所选赛事范围内的实际参赛记录。多选时合并各赛事的玩家指标总和与参赛场数，再计算均值，不对不同赛事的均值再次等权平均。“所有赛事”使用全部对局，统计口径相同。
- 所有玩家均值先分别计算单玩家均值，再等权求平均。
- 列表按平均排名升序排列；相同均值时参赛场数多者优先，再按 ID 排序。
- 雷达图五项分别以所选赛事范围内的最高玩家均值为外圈；全体为零的维度上限设为 1。同一赛事内切换玩家时保持尺度，切换赛事时重算尺度。真实均值显示在表格中，保留两位小数。
- `data/index.json` 包含“所有赛事”的排序列表、全体均值、尺度、统计概况，以及各赛事的名称和索引路径。
- `data/players/<ID的SHA256>.json` 每位玩家一个文件，包含原始 ID、均值、参赛场数和各场记录（含 Sheet、对局序号、源行号）。使用哈希文件名避免 ID 中的特殊字符影响路径。
- `data/events/<Sheet名的SHA256>/index.json` 保存该赛事的统计；同目录的 `players/<ID的SHA256>.json` 按玩家存放该赛事的均值及记录。
- 索引中的玩家条目包含各指标总和 `totals`，页面可直接汇总勾选赛事，无需为多选下载全部玩家的逐场记录。各玩家文件仍保留完整对局数据。
- 构建只发布页面与 JSON，不复制 Excel、Python 或 BAT。

独立生成：`python wxq/process_data.py`。可传入 Excel 路径及 `--output` 输出目录。

统计规则检查：`python -m unittest discover -s wxq -p "test_*.py"`。
