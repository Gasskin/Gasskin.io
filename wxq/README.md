# 万象棋对局统计

## 更新数据

1. 将所有对局整理到本目录的 `data.xlsx`（可分多个工作表分页，名称以 `##` 开头的分页会被忽略），保存 Excel。
2. 双击 `生成数据.bat`。需要 Python 3；首次运行若缺少 openpyxl，会通过 pip 安装本目录 requirements.txt 中的依赖。
3. 生成成功后会自动运行项目 `build.py`，将页面和 JSON 同步到 `docs/`。刷新网站中的“万象棋”分页。

页面提供“玩家数据”和“阵容数据”两个视图，统一展示所有有效分页整合后的统计数据，不再区分或筛选赛事。

- **玩家数据**：左侧支持按平均排名、胜率（第一名）或前三率（排名 ≤ 3）排序并搜索玩家；右侧展示该玩家的平均排名、胜率、前三率、参赛场数、五维雷达图（可对比平均值或其他玩家）以及该玩家使用的所有阵容数据（场数、使用率、平均排名、胜率、前三率）。
- **阵容数据**：汇总所有有效阵容记录，展示各阵容的出场次数、平均排名、胜率与前三率，并支持排序和搜索。

本地浏览使用项目根目录的 `python dev_server.py`，打开 `http://127.0.0.1:8765/#wxq`。请通过 HTTP 访问，直接双击 HTML 无法读取 JSON。更新线上网站仍需按项目现有 GitHub Pages 流程发布。

## Excel 格式

读取所有工作表，包括隐藏工作表；名称以 `##` 开头的工作表（例如 `##散排`、`##备注`）整张跳过，不校验内容，也不计入统计。名称中间包含 `##` 的工作表仍正常处理。其余所有有效工作表的数据统一整合统计，每张表按前七列（可选第 8 列“阵容”）解析，依次为：

`ID | 排名 | 获得能量/经济 | 对棋手伤害/攻击 | 总回合数/生存 | 单回合最多升级/成长 | 单回合最多出牌/操作 | 阵容（可选）`

首列为 `ID` 的行开始新对局，直到下一个表头或当前工作表结束。空行跳过，不切分对局；空白工作表跳过。维度按 `/` 后面的名称识别，顺序保持一致。不带前缀的“经济”等表头也支持。阵容单元格为空时，该条对局仍计入玩家自身对局统计，但不计入阵容数据与玩家阵容使用率。

- 玩家 ID 去除前后空格后精确匹配，不同 Sheet 中相同 ID 合并。
- 同一场不允许重复 ID；错误提示包含 Sheet、行号和 ID。
- 排名必须为正整数；其余指标必须为非负有限数值。零为有效数据，空值和错误值不能充当零。
- 如果使用 Excel 公式，需要先在 Excel 中计算并保存；脚本读取已保存的计算结果。
- 所有数据校验通过才写入 JSON；校验失败保留上次 JSON，不修改源 Excel。

## 统计和文件

- 所有有效工作表中的同一玩家记录统一合并计算均值、总和、胜率（排名 = 1）和前三率（排名 ≤ 3），不按赛事拆分。
- 所有玩家均值先分别计算单玩家均值，再等权求平均。
- 雷达图五项分别以全体玩家中的最高均值为外圈；全体为零的维度上限设为 1。
- 阵容统计忽略空单元格；玩家详情中的阵容使用率以该玩家拥有有效阵容记录的场数为分母。
- `data/index.json` 包含所有玩家的排序列表（含均值、胜率、前三率及个人阵容统计）、全体均值、雷达尺度、全局阵容统计 `lineups` 及统计概况。
- `data/players/<ID的SHA256>.json` 每位玩家一个文件，包含原始 ID、均值、胜率、前三率、个人阵容统计和各场记录（含来源 Sheet、对局序号、源行号及阵容）。使用哈希文件名避免 ID 中的特殊字符影响路径。
- 构建只发布页面与 JSON，不复制 Excel、Python 或 BAT。

独立生成：`python wxq/process_data.py`。可传入 Excel 路径及 `--output` 输出目录。

统计规则检查：`python -m unittest discover -s wxq -p "test_*.py"`。
